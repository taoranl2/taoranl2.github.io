{%- comment -%} Interactive map of visited national parks. State outlines come from _data/us_states.yml (generated — see the header of that file). Pins are placed in the browser by projecting each park's lat/lon from _data/parks.yml, so adding a park needs no regeneration. Without JavaScript the map still renders and the visited states stay tinted; the pins and tooltips are the enhancement, and the full list sits below. {%- endcomment -%} {%- comment -%} Build a pipe-delimited set of visited states. Both the dedup test below and the lookup further down must include the delimiters, or a state whose name is a substring of another already in the set is silently skipped — "Virginia" inside "West Virginia" is the one such pair among the 50 states. {%- endcomment -%} {%- assign visited = "|" -%} {%- for park in site.data.parks -%} {%- assign probe = park.state | prepend: "|" | append: "|" -%} {%- unless visited contains probe -%} {%- assign visited = visited | append: park.state | append: "|" -%} {%- endunless -%} {%- endfor -%}
